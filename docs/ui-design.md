# Yarn Workbench UI 規範

版本：Windows 0.3.0，2026-09-18。適用於深色桌面與網頁工作區。

依使用者批准的 M0–M6、flat-tags-v5，以及 2026-09-18 的 D01–D10 重設與 SVG icon 要求更新。原始截圖、缺陷與決策依據保留於[桌面設計複審](desktop-design-review-2026-09-18.md)；本文件是現行規則，不將舊版缺陷當作設計標準。

## 框架與導航

- Windows 第一列44px，包含專案、文件tabs及原生titlebar overlay。保留系統caption安全區、可拖曳留白與不可拖曳的互動區。
- 第二列42px：返回／前進、文件身份及保存狀態、模式分段控制、文件工具。移除第三條圖表標題與常駐統計footer。歷史預覽直接替換本列工具，不再疊列。
- 分頁浮動表面，選取不疊強外框與底線。文件使用穩定的SVG文件圖示，僅同稿多視圖補模式／編號。固定用Pin SVG；＋跟在最後分頁，溢位仍可取得＋及完整分頁清單。
- 文件樹在左（預設220px，可調180–420）；場景大綱在右（260px），初次收起，可按模式固定。1280px以下一次保留一個輔助欄，最近開啟者優先；1000px以下為暫時抽屜。響應式隱藏不覆寫固定偏好。
- 全文搜尋替換左側文件樹，保留查詢、選取、列表捲動與最近查詢；按文件分組、命中高亮，上限300筆須明示。滑鼠與Enter使用相同模式；提供明確的純文字定位動作。
- Ctrl+P使用快速開啟浮層：Enter重用視圖、Ctrl+Enter新視圖。＋／Ctrl+T已表達新增分頁，選擇器預設開新視圖。方向鍵與可見選取一致。
- 設定、自訂指令、專案復原各有完整工作區，不保留無關的劇本樹／場景大綱。設定分類180px、內容最大720px；初始焦點在可見分類標題。

通用reset置於base layer，不覆蓋元件utilities。共用元件在components，工作區、閱讀、圖表及指令各有自己的CSS。原生Windows控制不自行重畫。

## 保存、歷史與設定

- 已寫回文件顯示低權重保存狀態，無常駐Save；Ctrl+S及Save All仍可用。草稿顯示「已保留本機草稿」與「存成檔案」，不可同時以未保存圓點示警。進行中、失敗、缺檔與衝突分開呈現。
- 時鐘入口只開目前文件歷史。右側按日期排列版本，中央明示唯讀，內容／差異用分段單選。預覽不建立交易、不觸發自動寫回；切回保留原編輯面與位置。
- 還原先保留目前內容；主程序檢查預覽時的版本與文字。預覽後其他視窗修改時，停用舊比較的還原，要求重新比較。
- 最近刪除屬專案，與指令復原有独立專案工作區；文件版本不與刪除清單混排。先預覽再明確還原。
- 設定只保留「顯示與閱讀」「編輯與保存」「快捷鍵」「關於」分類，不為每種偏好開小modal。小modal留給命名、衝突處理及必要確認。
- 指令工作區是清單＋定義，明示專案範圍。參數採緊湊列；「套用定義」置於表單頂部，已套用時停用；副本、Undo／Redo用有提示的SVG，刪除與低頻操作放所屬選單。非法定義保存為草稿，不覆蓋有效設定。

## 閱讀編輯

純文字模式維持Monaco原樣。閱讀模式是CodeMirror的單一連續編輯面，裝飾只映射來源範圍，不能從DOM重新生成Yarn。所有分支都呈現，不模擬執行。

- 標準欄最大760px，寬版900px，隨可用空間縮小；條件區域與分隔不超過閱讀欄。正文16／29px起，標題1.4em、命令0.875em、變數0.9em、tags 0.75em，整套隨閱讀字級變化。
- 角色與台詞同列，連續台詞不加大片空白。場景、命令組與選項用少量間距分層；來源空行只壓縮呈現，保留註解、空白、BOM與換行。
- tags緊接場景標題，灰色小標籤、無圖示與隨機色；變數使用淡紫標籤，隱藏$，保持識別字。字串、註解、未知markup中的字面$不誤轉換；set左右運算元規則一致。
- 通用命令用terminal SVG＋名稱＋原順序參數，jump用箭頭＋目的地，set用指定箭頭；detour與jump保持不同語義，不憑命令名稱猜音效或動畫。
- 條件共用淡色平面區域，若／否則以分界連為同一判斷，結束有明確下緣。深層保持相同閱讀起點，在上下文變化處顯示父路徑；選項後共同內容不得誤屬else。
- 選項用藍色折箭頭與文字，下接所屬命令／台詞；簡單jump保持鄰近兩行，不為省一行破壞連續選取。
- 游標／選取觸及token才揭露必要原文；命令分隔符需完整揭露，結構編輯有低權重提示。未知／未完成語法回退原文。IME期間只映射既有裝飾，結束再計算。
- 場景折疊為暗色緊湊列、SVG箭頭與標題對齊，不保留展開外距。折疊範圍存於分頁，隨來源修改映射；來源不再符合完整場景時展開，避免錯折。

## 流程圖

- 圖表示靜態跳轉，拖動只改布局；相關說明放資訊入口，不常駐畫布。
- 普通節點232px寬、12px內距、自然高度，只留標題及最多兩行正文預覽。tags、行號、命令放詳情；跨檔為緊湊入口，保留相對檔名，取消強白邊。
- Link保存完整選項／條件祖先、inline條件、elseif／else前置條件及來源。未知條件明示未解析；jump／detour分組不混淆，不求值。
- 路線避免卡片，往返分離端點與路徑。標籤附於所屬線段，不畫長斜虛線；無合適位置時由詳情承接。縮遠隱藏微小細節，選取詳情仍可讀完整前提。
- 一般選節點不自動打開詳情；明確開啟後記住。選取凸顯鄰接關係，點空白清除。
- 搜尋、縮放、fit、自動整理、布局Undo／Redo及詳情集中畫布角落。搜尋顯示多結果／零結果並可循環定位，Esc回焦點。
- 初次fit等待實際節點尺寸與畫布就緒，納入卡片、路線與標籤邊界；保存過的视野優先。每張tab獨立保存圖表布局與撤銷紀錄。

## 驗證與歷史

現行結果與限制以[實作追蹤](implementation-progress.md)為準。pnpm test:workspace、test:graph、test:reading驗證內容及布局；test:workspace-ui測保存與跨窗；test:ui-redesign測新版導航、設定、搜尋與歷史。所有桌面測試使用隔離profile。

必測800／1100／1440px、少量／大量tab、長名稱、focus／selected、未知與未閉合來源、條件／選項祖先、只預覽後取消、還原與其他視窗同時編輯、折疊跨模式與重啟。

原生中文IME、Snap、原生tab拖出／拖回、多螢幕／不同DPI、讀屏與安裝精靈仍須專項實測，不以Playwright網頁輸入替代。0.1.1的[歷史視覺審查](desktop-ui-visual-review-2026-09-17.md)與0.2.1[複審](desktop-design-review-2026-09-18.md)不代表0.3.0畫面。
