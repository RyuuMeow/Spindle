# Play 试跑

Spindle 0.11.0 Windows 版提供小说／VN 试跑、角色、运行状态检查、回溯及编辑器开始模式。Web Play、音频、完整来源入口、命名测试与 agent 操控属于后续阶段。

## 操作

从模式切换旁的 Play 按钮启动。启动期间及 Play 窗口打开时，按钮显示活动反馈；再次点击会中断试跑并关闭该窗口。直接关闭 Play 也会重置编辑器按钮。每个编辑器窗口有独立 Play 窗口与 runtime；单文件模式只编译该文件。

右键 Play 选择启动模式：“默认”使用设置 → Play 的开始场景名（初始为 `Start`）；“当前文件”从该文件原文顺序中的第一个场景开始；“当前行”请求经过安全验证的直接来源入口。勾选模式及开始场景保存在本机 App profile。切换模式只影响下次启动，不改变正在试跑的内容。场景不存在或来源入口无效时会明确报错，不偷偷选择其他位置。

编辑器 Play 按钮在图标旁显示开始模式。设置 → Play 的开始场景改为可搜索下拉菜单，列出当前工作区所有文件的场景；打开后输入可筛选，以方向键及 Enter 选择，Esc 取消。已保存但不在此工作区的场景保留原值，直到明确选择另一场景。故事区不显示常驻开始模式提示栏。

当前行目前接受最外层、不含插值的独立台词（包括旁白）。使用声明初始值并跳过前文执行，编辑器按钮的 tooltip 说明此行为；场景其他位置有条件或选项不再阻挡；官方语法树识别出的分支内台词、行内条件，以及标头、注释、指令与插值入口仍会被拒绝。重跑保留快照入口；入口文件已修改时，必须回到编辑器重新启动，避免旧行号指向不同内容。

小说模式累积台词，VN 显示背景、三个立绘位置与对话框。切换呈现不重置状态。第一次推进补完打字机，下一次才推进。Auto 遇选项保留开启状态、暂停推进，手动选择后继续；错误则停止 Auto。侧边面板提供变量搜索、固定、类型输入、条件、指令事件与原文定位；不可用选项仍显示，不猜测 runtime 未提供的原因。

上一步还原台词、选项或测试覆盖停点，包括 VM、变量、访问、随机、事件与画面。改选后不保留旧路径结果。选项等待时改变变量，只重新计算该组选项，不重播之前指令。覆盖不修改剧本。

## 角色与素材

Project 菜单、搜索及 Play 可打开“角色与预览”。从台词发现说话者，显示名称不改写原文。导入 PNG、JPEG、WebP，设置默认头像、具名头像／立绘变体后自动保存；缺图使用色块替代。

设置保存于 `.spindle/preview.json`，素材保存于 `.spindle/preview-assets/`，以相对引用及内容哈希识别。单张上限 20 MB，快照加载上限 100 MB。保存核对修订，损坏设置不覆盖。

自定义指令页提供背景、显示、隐藏、表情等声明式预览效果；参数索引由 0 开始，站位为左／中／右。角色页也能设置同一份映射。未绑定指令只显示实际求值事件并继续，不执行 JS、shell 或游戏逻辑；运算所需的未知函数会明确报错。

## 版本、来源与整合

试跑固定已同步的内存文件、指令及素材设置；输入法组字或未同步草稿会阻止获取。修改剧本后本轮继续原版本，标示已更新。“重跑”使用原快照，“使用最新内容重跑”才重新编译。查看原文仅安全映射未变范围，歧义时打开只读快照。

阅读画面使用默认头像，不改来源坐标。图表只标示实际观察到的场景／路径，不重新排列、不清除 pin、不把未测说成不可达。关闭或重新绑定来源窗口会结束 helper，Play 本身没有剧本保存询问。

官方 Yarn Spinner 3.2.1 与 .NET 10.0.12 自包含 helper 随包离线运行，不需另装 .NET。私有标准输入／输出传递消息，不新增网络服务。每次推进限制 100,000 指令，每轮限制 10,000 事件，请求超时 30 秒；关闭 Play 可终止 helper。调试扩展集中于 vendor，保留官方编译及求值规则，执行状态不持久化。

MCP 新增 `list_play_sessions(editorSessionId)` 与 `get_play_context(editorSessionId, playSessionId)`，只读模式可用。情境与编辑器选区分离，长内容明示截断；MCP 操控试跑及来源入口操作留待后续。

## 构建

使用项目指定 Node/pnpm 与 .NET SDK 10.0.401，可用 `SPINDLE_DOTNET` 指向私人 SDK。先执行 `node scripts/build-play-runtime.mjs`，再执行 `node --test scripts/play-runtime.test.mjs scripts/play.test.mjs`。桌面 staging 自动打包 self-contained helper 及授权。

`node scripts/test-play-ui.cjs` 以隔离 profile 验证实际 Electron 与 MCP client；设置 `SPINDLE_PLAY_PORTABLE` 可直接测试最终 Portable。详见[验收记录](play-validation.md)。


## 桌面呈现

工具栏、调试区及逐行小说沿用 Spindle 的色彩、字体与控件 tokens。VN 使用独立游戏呈现：内缩半透明消息框、相接的角色姓名标签、无衬线正文及居中选项。原文外链只留在调试区，不进入 VN 舞台。游戏画面隐藏编辑控件；Esc 退出后焦点回到入口。窄窗口的调试区只在请求时覆盖打开，不挤压舞台。

正文固定保留两行。VN 不显示页码或「继续」按钮文字；可推进时只显示小型待续三角，点击对话区或使用键盘推进。点击先补完当前页，再切换呈现页；最后一页才推进剧情。超长台词按实际排版分页，保留完整字符，不滚动或缩小字号；改变窗口大小时保留来源字符锚点。鼠标、键盘与 Auto 共用此规则。VN 使用游戏指针，不提供文字选择；拖动不推进。小说逐行内容后的透明留白也能推进，可操作时显示闪烁提示。点击或 Enter／Space 先补完文字、再推进；拖动、向上回读及等待选项不会代选答案。减少动态效果时提示保持静止。VN 接受连续快速点击，包含双击的第二下；执行请求未完成时不重复发送。打开对话记录、查看原文及小说向上回读均停止 Auto，错误也会停止；选项只暂停推进，不重置开关。小说回读位置在切换模式后保留。系统减少动态效果设置会禁用打字机动画，但不改写原偏好；重跑建立新的本轮标识，即使第一句相同也会重新呈现。

## 呈现与保存

Characters 合法修改停止输入 400ms 后自动保存，字段失焦或切换角色时完成待保存内容。组字及无效输入保留草稿；远端不同字段安全合并，同字段冲突可重新加载或明确重新提交本地更改。不再需要日常保存按钮；单纯选择扫描到的说话者不会创建项目数据。

编辑器风格提供头像及姓名色开关，Source 姓名色另有独立开关。设置 → 试跑的头像开关只控制小说模式，姓名色开关控制两种 Play 呈现，跨窗口即时生效而不改变本轮状态。自动色依原文姓名稳定分配，自定义色保持原值。缺图使用色块，关闭头像不留占位，且不影响 VN 立绘或背景。VN 姓名牌不显示头像。

编译结果使用独立底部面板，可由工具栏切换、关闭、鼠标拖动或键盘调整高度，并保存视图。新的编译失败展开一次，一般状态更新不会重开已关闭的面板。沉浸模式的“查看编译结果”返回工具视图。VN 待续三角纯属装饰；点击对话区或 Enter／Space 推进，Auto／记录为纯文字游戏菜单；Auto 以 ON／OFF 及明显色差标示状态。两种呈现的场景与来源信息放在调试侧栏，不放在故事区。停止只结束本轮、保留窗口与调试记录；窗口关闭按钮才关闭 Play。
