# Spindle 界面规范

编辑器 Play 按钮在图标旁显示开始模式。设置 → Play 的开始场景改为可搜索下拉菜单，列出当前工作区所有文件的场景；打开后输入可筛选，以方向键及 Enter 选择，Esc 取消。已保存但不在此工作区的场景保留原值，直到明确选择另一场景。故事区不显示常驻开始模式提示栏。

编辑器 Play 按钮在启动中或活动时显示暂停图标，操作明确为“中断并关闭 Play”，不是暂停 runtime。右键或 Shift+F10 打开可持久保存的单选启动菜单。小说待续符号水平居中、靠透明推进区顶端排列，距离顶端 12 CSS px；整片区域仍可点击。详见[启动规则与来源入口限制](play.zh-CN.md)。

## 角色呈现与写作提醒

角色与预览沿用指令工作区结构：全高角色列表与平面编辑区分隔，各自滚动；窄版使用抽屉。预览效果沿用指令表单的内容边距与宽度。角色呈现开关各占一行，不以相邻行内标签排列。

编辑器头像默认关闭，阅读与图表的角色姓名色默认开启；Source 角色色单独开启。Play 小说头像与姓名色默认开启；VN 姓名牌不显示头像。自动色根据原文角色名稳定生成，已有明确色值保留为自定义色。缺少头像时使用纯色替代图与中性边框；显示名称不替换 Yarn 原文、不改变选区来源位置。

角色与预览效果在有效输入停止 400ms、且输入法组字结束后静默保存。仅选择扫描到的角色不创建或保存角色。独立字段可合并较新项目数据，冲突保留输入供重试；关闭工具 tab 或离开项目前先保存草稿。指令定义草稿仍沿用现有应用／丢弃流程。

台词长度提醒默认开启，上限 80 加权字符：CJK、全角与 emoji grapheme 计 1，其余 grapheme 计 0.5。排除角色前缀、已识别语法与未求值动态片段；这是静态估计，不是 VN 容量或编译错误。沿用 800ms／IME 诊断呈现规则，不自动截断或改写台词。

验证：单元测试覆盖偏好、保存、诊断与 decoration。本轮仍待统一桌面 UI 实机验收，不能视为新版 Portable 已验证。

以下是当前深色 Windows 桌面和 Web 工作区的设计规则。旧评审保存在 [history/](history/)；[验证报告](../releases/0.10.0/verification.md) 区分已实现功能和未实测设备场景。界面支持 English、繁體中文、简体中文；Yarn 原文、用户剧本和自定义命令内容不翻译。

## 首页与项目

首页与编辑器分开，提供「打开项目文件夹」「创建项目」、可搜索的完整项目列表及全局设置。失效路径使用 SVG 警告和较低文字亮度，仍可从列表移除，但不能打开或改名。创建表单显示父文件夹及完整目标位置，同名目录不合并。Project 菜单只显示最近五个项目；从最近列表移除不会删除完整列表记录。关闭项目先保存再回首页。独立 `.yarn` 窗口隐藏项目专属操作。旧无路径草稿在「设置 → 数据恢复」管理。

## 工作区、标签与导航

Windows 第一行是 44px 标题／标签栏，保留原生窗口控制区；第二行是 42px 导航及模式栏。Project 与标签之间有居中的 1px 分隔线。左侧是文档树，右侧是当前文档大纲；大纲由工具栏切换，并在普通导航中保留偏好。窄窗口可暂时让位给另一辅助侧栏，不覆盖保存的展开状态或宽度。分隔控件支持 hover、焦点和键盘调整。

标签页是**视图容器**，不是文件的唯一实例。点击文档树、普通搜索结果、大纲或诊断，在当前 TabId 导航并保留模式。中键、Ctrl+Enter、标签加号或明确的「新标签打开」才创建容器。每个标签独立保存导航、选区、滚动与图表视野；同文档视图共享文字和 Undo。切换设置、命令或恢复标签不重置其控件或 diff 预览。

新增剧本／场景在所属列表行内命名。Enter 或合法失焦提交，Escape 取消且不建立空文件／来源区块；输入法 Enter 不提交。非法名称或 I/O 失败保留输入。文件夹箭头有固定 24px 控制栏、居中 SVG，**无 hover 背景**；点箭头展开，点名称选取，双击改名。文件树拖动以白色插入线提示，普通删除进入 Spindle 垃圾桶。

## 统一搜索与创建

全局搜索、Ctrl+P 和新增标签共用约 680px、靠上居中的轻量浮窗，不压暗背景也不要求确认按钮。全局搜索默认「全部」，Ctrl+P／加号以文件为主；可搜索文件名／路径、剧本文字、设置字段、自定义命令和操作。空查询先显示「新建剧本」，再列最近文件及设置／命令入口。`New`、`新增`、`新建` 均能找到创建操作。查无结果且查询是合法文件名时可「新建〈查询〉为剧本」；非法名称显示原因。结果标明类别和必要上下文。设置结果定位分类／字段；命令结果定位定义，不擅自应用草稿。

方向键移动选取，Enter 打开，Ctrl+Enter／中键开新标签，Esc 恢复焦点。中文组字确认不能触发导航。焦点在输入框与结果之间移动不关闭浮窗，离开整个浮窗才关闭。从搜索创建剧本时，先打开**暂存编辑标签**，命名成功后才创建磁盘文件；取消只移除暂存标签并返回来源标签，其他工具标签状态保持不变。

## 编辑辅助、诊断与阅读

纯文本补全及自定义命令说明沿用圆角、分层的帮助浮窗；不保留 Monaco／VS Code 默认方框。诊断 hover 优先于一般命令说明，同时最多显示一个辅助浮窗。空位置参数显示提示，不因暂时缺值诊断而被遮住。Find 按钮与关闭图标对齐，tooltip 不覆盖或闪烁挡住按钮。纯文本光标和选区高度接近文字而非整行高。风格设置提供全局默认与逐模式继承；App 工具栏保持自己的字体与颜色。

输入、删除、粘贴及 Undo/Redo 立即隐藏当前编辑范围的波浪线、错误浮窗和自动修复，语义分析仍供即时补全。停止输入 800ms 或游标离开正在编辑的命令／行后发布最新诊断；输入法组字期间继续保护。问题侧栏与数量沿用最近一次完整发布。手动检查及 Alt+Enter 可立即检查已完成输入。已删除或无法安全映射的旧诊断不能残留。

阅读编辑保持可直接修改的对话排版；纯阅读隐藏指令／标签但不改原文。大纲与跨文件定位按来源范围展开目标。图表分别保存手动布局：用户主动自动整理，卡片／pin 可移动，分支成组及局部修线。点击线或条件卡只选取，不自动开侧栏。布局手势使用独立 Undo，节点文字使用文档 Undo。

## 恢复、保存与确认

项目历史、文档历史、命令版本及垃圾桶各有边界。选中垃圾桶项目可预览而不导航离开；恢复后移除该项目，停留在恢复页，并选择下一／上一项。切换版本不重置 diff 模式。单项／全部永久删除需要精简确认，不能误删现存剧本或命令版本。正常保存保持安静；失败或耗时较久的离开保存才显示状态。切换项目、关闭、重启需先保存相关工作区，成功后再关闭编辑器。未应用命令草稿在重启／更新前须应用或丢弃；普通关闭命令标签会丢弃。

界面表面分为外壳、停靠面板、编辑区与浮层。停靠面板使用小间距、克制对比及小圆角，阴影主要给浮层。补全、快速修复、Find、设置与菜单保持一致的圆角组件；hover／选取／禁用时几何不漂移。App 内指南链接应匹配界面语言；Skill 和法律原文保持英文。

## Play 呈现规范

桌面 Play 的工具栏、小说与调试区共用编辑器的字体、表面、焦点和控件 tokens。VN 使用独立游戏美术表面：内缩半透明消息框、相接姓名标签及克制的选项。舞台不含来源外链，调试在侧栏。正文固定两行，超长台词只在呈现层分页；长选项列表独立滚动，VN 正文不提供文字选择，小说阅读交互不变；减少动态效果也禁用 JavaScript 打字机。Auto 使用明确 ON／OFF 文字及色差，选项等待保留开启状态。场景与来源状态位于调试侧栏。操作与模式切换规则见 [Play](play.zh-CN.md)。
