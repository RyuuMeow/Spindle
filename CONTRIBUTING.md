# Contributing

Please open an issue describing the problem and expected behavior before a broad change. Include the app version, Windows version and reproducible steps; never attach credentials or private project contents.

Use the pinned Node and pnpm versions. Run type checking, lint, relevant tests, translation checks and both builds. UI changes should include screenshots from a disposable project. Keep diagnostics and MCP backed by the same semantic services.

Changes are contributed under GPL-3.0-only. Preserve third-party notices. Product versions come from `version.json`; release descriptions live under `releases/`.
