# The Last Light / 最後一盞燈

A small Yarn story for trying scene navigation, choices, conditions, variables, and the flowchart. The three scripts and two custom command **definitions** are sample content; the game must implement `fade_in` and `play_sound` separately.

Copy this entire folder to a personal location, then choose **Open project folder** in Spindle. The `.spindle/project.json` file contains no fixed project or document IDs; Spindle assigns them to your copy when it opens. Editing this example never changes the application’s default workspace.

The same scripts and command definitions generate `scripts/fixtures/sample.ts` for tests. After changing the example, run `pnpm demo:sync` and commit both the example and generated fixture.
