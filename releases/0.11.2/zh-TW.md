# Spindle 0.11.2

## Features
- 修正分頁拖曳、刪除文檔後的分頁行為，以及多語台詞編輯提示。

## 修正
- 分頁列最前面的插入線不再被裁掉；拖到分頁間隙會插入該位置，不會移到最後。取消拖曳或沒有有效插入預覽時不會變更排序。
- 刪除文檔保留分頁、順序與固定狀態。各分頁返回上一份仍存在的文檔；沒有歷史則保留空白分頁，之後開檔沿用該分頁。
- 中文全形標點不再觸發純文字編輯器的相似字元警告，仍保留不可見字元提示。

## 發行
Windows x64 Portable 與 NSIS 安裝版均未簽章。包含全部 0.11.1 修正；已完成的驗證及未實測情境見驗證報告。
