# Spindle 0.11.2

## Features
- 修复标签页拖动、删除文档后的标签页行为，以及多语言台词编辑提示。

## 修复
- 标签栏最前面的插入线不再被裁切；拖到标签间隙会插入该位置，不会移到最后。取消拖动或没有有效插入预览时不会更改排序。
- 删除文档保留标签页、顺序和固定状态。各标签返回上一份仍存在的文档；没有历史则保留空白标签，之后打开文件沿用该标签。
- 中文全角标点不再触发纯文本编辑器的相似字符警告，仍保留不可见字符提示。

## 发行
Windows x64 Portable 与 NSIS 安装版均未签名。包含全部 0.11.1 修复；已完成的验证及未实测场景见验证报告。
