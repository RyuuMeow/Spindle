# Spindle 0.10.0

## Features
- Search scripts, content, settings and commands from a unified palette.
- Create scripts in a new tab with inline naming and safe cancellation.
- Choose English, Traditional Chinese or Simplified Chinese.
- Manage legacy drafts from Data recovery in Settings.
- Check for stable releases and install updates after saving every workspace.

## Changes
- Shared version metadata and offline language resources.
- Public-facing documentation, licensing and reproducible Windows release workflows.
- Existing editor layouts, project history and MCP integrations are preserved.

## Distribution
Windows x64 Portable and NSIS packages are unsigned. The verification report lists tested and untested update scenarios.
