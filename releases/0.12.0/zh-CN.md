# Spindle 0.12.0

## Features
- 支持定义成对或自闭合的行内标记，纯文本、阅读编辑与流程图均提供名称／参数补全、首尾联动编辑及快速修复。
- 阅读编辑与流程图以精简标签显示行内标记，使用可自定义的循环色板；嵌套或重叠范围以分层实线表示，点击标签只展开该组首尾源代码。
- 支持指令重载与参数限制，提供对应的签名、验证与补全。
- 可调整行内名称、参数及分隔符的语法颜色，指令侧栏也可拖动调整宽度。

## Fixes
- 纯阅读隐藏标记、指令与注释，移除首尾空白行，内容之间最多保留一行空白；原稿与选区位置保持不变。
- 未知行内标记可直接通过快速修复注册，无需离开编辑器。
- 修复流程图编辑器可能重新应用过期场景内容的问题。

## Distribution
提供未签名的 Windows x64 便携版与 NSIS 安装版，包含 0.11.2 修复。已完成的检查与验证范围请见验证报告。
