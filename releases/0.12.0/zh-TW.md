# Spindle 0.12.0

## Features
- 支援定義成對或自閉合的行內標記，純文字、閱讀編輯與流程圖皆提供名稱／參數補全、頭尾連動編輯及快速修正。
- 閱讀編輯與流程圖以精簡標籤呈現行內標記，使用可自訂的循環色盤；巢狀或重疊範圍以分層實線表示，點標籤只展開該組頭尾原始碼。
- 支援指令多載與參數限制，提供對應的簽章、驗證與補全。
- 可調整行內名稱、參數及分隔符的語法顏色，指令側欄亦可拖曳調整寬度。

## Fixes
- 純閱讀隱藏標記、指令與註解，移除首尾空白行，內容之間最多保留一行空白；原始稿與選取位置保持不變。
- 未知行內標記可直接透過快速修正註冊，不必離開編輯器。
- 修正流程圖編輯器可能重新套用過期場景內容的問題。

## Distribution
提供未簽章的 Windows x64 可攜版與 NSIS 安裝版，包含 0.11.2 修正。已完成的檢查與驗證範圍請見驗證報告。
