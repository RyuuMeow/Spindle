# Spindle 0.11.0

## Features
- 在獨立 Windows 視窗試跑故事，逐行小說與雙行 VN 呈現共用同一輪執行狀態。
- 查看變數、選項、指令事件與原文位置；回到上一步時還原執行及預覽狀態。
- 自動保存角色、頭貼、立繪及宣告式預覽效果，分別控制編輯器與 Play 的角色呈現。
- 保存 Play 開始模式：預設場景、目前文件或支援的目前行；預設場景下拉選單可搜尋整個工作區。
- MCP 助手除了既有的目前文件、游標及精確反白內容，也能讀取 Play 工作階段與情境。目前共 22 個工具，尚不提供 Agent 操控播放。

## 改善
- 新增加權台詞長度提醒，可設定門檻；輸入時維持安靜診斷。
- 統一角色／指令的清單編輯布局、可搜尋下拉選單、窄幅面板及可調整高度的編譯結果面板。
- 改善 VN 連續點擊推進、小說底部空白區推進、Auto 開關辨識，等待選項時保留 Auto 狀態。
- 減少純文字滾動、閱讀編輯視野更新及圖表縮放／平移的重複工作；保留手動節點位置與 pin。
- 修正新劇本失焦命名、風格分頁捲動、右鍵選單動畫及 Play 提示殘留。

## 執行核心與範圍
Play 內含官方 Yarn Spinner 3.2.1 編譯器／runtime 及自包含 .NET 輔助程序，不需另裝 .NET。本輪試跑固定使用啟動時的劇本版本，明確選擇最新內容重跑後才更新。自訂指令預覽對應不代表實作遊戲程式。

目前行起跑支援不含插值的頂層獨立台詞／旁白；巢狀分支、指令及運算式不能作為起點。Web Play、音訊、保存測試案例及 MCP 播放操作不包含在本版。
