# Spindle 0.11.0

## Features
- 在独立 Windows 窗口试跑故事，逐行小说与双行 VN 呈现共用同一轮运行状态。
- 查看变量、选项、指令事件与原文位置；回到上一步时恢复运行及预览状态。
- 自动保存角色、头像、立绘及声明式预览效果，分别控制编辑器与 Play 的角色呈现。
- 保存 Play 开始模式：默认场景、当前文件或支持的当前行；默认场景下拉菜单可搜索整个工作区。
- MCP 助手除了现有的当前文件、光标及精确选中内容，也能读取 Play 会话与上下文。目前共 22 个工具，尚不提供 Agent 操控播放。

## 改进
- 新增加权台词长度提醒，可设置阈值；输入时保持安静诊断。
- 统一角色／指令的列表编辑布局、可搜索下拉菜单、窄幅面板及可调整高度的编译结果面板。
- 改善 VN 连续点击推进、小说底部空白区推进、Auto 开关辨识，等待选项时保留 Auto 状态。
- 减少纯文本滚动、阅读编辑视野更新及图表缩放／平移的重复工作；保留手动节点位置与 pin。
- 修复新剧本失焦命名、风格标签页滚动、右键菜单动画及 Play 提示残留。

## 运行核心与范围
Play 内含官方 Yarn Spinner 3.2.1 编译器／runtime 及自包含 .NET 辅助程序，无需另装 .NET。本轮试跑固定使用启动时的剧本版本，明确选择最新内容重跑后才更新。自定义指令预览映射不代表实现游戏程序。

当前行起跑支持不含插值的顶层独立台词／旁白；嵌套分支、指令及表达式不能作为起点。Web Play、音频、保存测试用例及 MCP 播放操作不包含在本版。
